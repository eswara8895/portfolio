Employee Attrition Prediction

Overview: A predictive web application designed to identify potential employee attrition in organizations.

Problem Statement: High turnover can cost businesses significantly. This tool helps HR make data-driven retention decisions.

Solution: Built a user-friendly interface using Flask to take employee data inputs. Trained a Random Forest Classifier on a Kaggle dataset to predict likelihood of attrition. Exported the model using Pickle for efficient reuse.

Key Features: Real-time prediction, secure form input, minimalistic UI, downloadable report option.

Technologies: Flask, Scikit-learn, Python, pandas, Pickle, HTML/CSS

Image Colorization

Overview: A deep learning-based tool that adds color to grayscale images using neural networks.

Problem Statement: Many historical or black-and-white images lose emotional impact without color. This app brings them to life.

Solution: Trained a convolutional autoencoder using OpenCV datasets to understand pixel mappings. Built a user interface using PySimpleGUI to simplify the colorization process for end users.

Key Features: Drag-and-drop UI, side-by-side original and colorized preview, export to PNG/JPEG.

Technologies: Python, OpenCV, Keras, PySimpleGUI, NumPy
